# App Router in production

I've shipped several projects on the App Router. These are the patterns that
helped me most:

- Server Components by default, `"use client"` only when state or events are needed.
- Keep data fetching close to the component that uses it.
- Use `generateStaticParams` aggressively for SSG.
- Split client/server with `.client.tsx` / `.server.tsx` only when it clarifies.

What I avoid: business logic in `page.tsx`. Move it to `lib/`.
